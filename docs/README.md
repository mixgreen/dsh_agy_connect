# 发布与维护

1. 在干净工作区核对包版本、DSH 兼容声明、更新日志及 README 安装直链。
2. 使用锁文件安装依赖，执行 `pnpm check`；检查待提交清单中没有本地凭据、个人路径或生成文件。
3. 正常推送 `main`，确认远端 SHA。由该提交的干净检出重新构建、打包，检查 `.tgz` 含包清单、Cordis 补丁与预编译 Host、Client。
4. 在同一提交打 `Vx.y.z` 标签，对应 Release 附 `.tgz` 和 SHA-256 清单。重新下载，验证哈希及包内入口，不覆盖已有资产。
